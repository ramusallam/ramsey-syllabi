Course Description

Technology for Social Good is a project-based class where students practice human-centered design thinking on a real need in the world. This semester the theme is assistive technology for computer access. Students build low-cost, open-source adaptive controllers, switches, and sensors that let an end-user operate a computer using whatever motion they can reliably make, at a fraction of the cost of commercial gear. Assistive technology lets individuals with disabilities participate in society on the same terms as everyone else.

Course Outline

  • Project 0: Meet the Mission
  • Project 1: Basic Adaptive Switches
  • Project 2: No-Force Sensors
  • Project 3: Hands-Free Controls
  • Project 4: Adaptive Controller Hub
  • Final Project: Instructable

AI Policy

You may use AI engines (ChatGPT, Google Gemini, etc.) for tips, further explanations, and feedback, but not to produce or complete work you present as your own. Always check AI output for accuracy. For assessments and graded work, AI is only permitted when explicitly stated. In this course, AI is part of the work: you will use it in the Vibe Coding tool to write and debug the Arduino code that runs your prototypes.
